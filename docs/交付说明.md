> **本机 HTTPS 证书说明**：本机域名解析与 HTTPS 经 SteamTools 代理（`127.0.0.1:49747`）转发，
> 该代理会用自签根证书替换远端证书，因此 `git push` 曾报
> `CRYPT_E_NO_REVOCATION_CHECK`（schannel 吊销检查失败，并非证书不受信任）。
> 处理方式：导出 SteamTools 根证书与 Git 自带 CA 包合并为
> `%USERPROFILE%\.git-ca\ca-bundle.crt`，并配置
> `git config --global http.sslBackend openssl` 与
> `git config --global http.sslCAInfo %USERPROFILE%/.git-ca/ca-bundle.crt`。
> 如需还原：`git config --global --unset http.sslCAInfo` 与 `--unset http.sslBackend`。
