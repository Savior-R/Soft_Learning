# Exp01 软件配置管理实验项目

本仓库用于《软件体系结构》实验 01 —— 软件配置管理的团队协作演练。

## 项目简介

以一个最小的 C 示例工程为载体，验证 SVN 集中式配置管理与 Git 分布式配置管理的
基本工作流：检出、更新、提交、查看历史、解决冲突、版本回退。

## 团队成员

| 角色 | 账号 | 职责 |
| --- | --- | --- |
| 成员 A | memberA | 初始化仓库、提交初始版本 |
| 成员 B | memberB | 修订文档、提交功能分支 |
| 成员 C | memberC | 同步验证、代码评审 |

## 目录结构

```
exp01/
├── readme.md          项目说明
├── src/               源代码目录
└── docs/              实验文档
```

## 构建与运行

```bash
gcc -O2 -o exp01.exe src/main.c
./exp01.exe
```

## 分支约定

- `main`：受保护主干，只接受合并请求
- `feature/*`：功能分支，一人一支
- 提交信息格式：`<type>: <subject>`，type 取 feat/fix/docs/chore

## 环境要求

- 操作系统：Windows 10/11 x64
- 编译器：gcc 9.0 及以上（或 Dev-C++ 5.11 自带 TDM-GCC 4.9.2）
- 版本控制客户端：Git 2.30+ / TortoiseSVN 1.14+

## 贡献指南

1. 从 `main` 拉取最新代码，切出 `feature/<主题>` 分支；
2. 小步提交，一次提交只做一件事，提交信息写清"做了什么、为什么"；
3. 推送后用 Pull Request 发起评审，至少一名成员 Approve 后合并；
4. 合并后删除已完成的特性分支，保持分支列表干净。
